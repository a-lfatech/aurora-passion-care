# Aurora Passion Care

Website for Aurora Passion Care - private in-home care and support services in Calgary, Alberta.

A new dawn of human-centered care.

## Development

```
npm install
npm run dev
```

## Build

```
npm run build
```

Environment variables `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` are required (not committed).
